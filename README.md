# Sebby's Console
Welcome to my console project! :)

This was a console, controller, launcher and game made for a Hack Club event that was required to be completed in 4 weeks with one week focussed on each part. It was really fun and challenging (however sometimes stressful near deadlines) and I hope to join in with a few more events in the near future.

My project is centred around the game I created for it, eventually titled "Flynn's Shenanigans", in which the player has to survive natural disasters like meteor showers and tornados on various different maps and um... yeah thats the whole game loop but it's fun though trust. The controller includes buttons that will be mapped to the game including two joysticks for character and camera movement, there's also a couple extra buttons like a button to go back to the launcher or for use in any other games that I make for the console. The launcher was super fun to work on and honestly probably my favourite, it includes three themes from some of my favourite games of all time along with related music for each one. The console I didn't get to spend a lot of time on due to being busy however I got a case design down that will snugly fit a raspberry pi.
